Model Architecture Details

Baseline

  • User-based CF
  • Cosine similarity on mean-centered vectors
  • Neighborhood size: adaptive (top-N by similarity)

Deep Learning (Two-Tower)

  • User tower: user ID embedding ⊕ gender ⊕ age bucket ⊕ occupation embedding → linear
  • Item tower: movie ID embedding ⊕ genre multi-hot → MLP (hidden ReLU) → linear
  • Score: dot(user_tower, item_tower) → scaled to rating range
  • Training: mini-batch SGD on existing ratings (few epochs)
